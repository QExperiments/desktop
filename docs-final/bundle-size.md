# Bundle size report

Generated by `npm run build:full` on darwin-arm64. Model weights are excluded:
they are fetched after install (req 1.2), not shipped in the installer.

| Build | Plugins | Worker bundle | Native addons, all hosts | Native addons, darwin-arm64 |
|---|---|---|---|---|
| full SDK | 12 | 11.7 MB | 4811.0 MB | 157.0 MB |
| plugin-scoped | 4 | 9.6 MB | 1654.3 MB | 71.5 MB |

Application code (`dist/meridian-assistant.mjs`, esbuild, tree-shaken,
minified): **1.1 MB**.

## Reading it

- **Worker bundle** is the JavaScript the Bare worker runs, generated by
  `bundleSdk` from the `plugins` array in `qvac.config.json`. Scoping cuts it
  by 18%.
- **Native addons** are the llama.cpp, whisper.cpp and TTS binaries the
  plugins load. Scoping to the 4 packages we use cuts the
  all-hosts footprint by 66%; keeping only this host's
  prebuilds brings what an installer for this platform carries to
  **71.5 MB**, 99% less than the full SDK with every
  platform's binaries.
- Scoped addons: `@qvac/asr-ggml`, `@qvac/embed-llamacpp`, `@qvac/llm-llamacpp`, `@qvac/tts-ggml`.

The last column is the number for the IT lead: what an MDM push for one
platform contains, before weights.
